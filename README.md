# 九九乘法大冒險

給小朋友的數學練習遊戲。可以選 1～9 的數字，先看卡片複習，再來挑戰考試，或練習康軒風格的「倍的問題」應用題；另外還有「時鐘教學」，用會動的時鐘學會分清時針、分針和怎麼看時間；以及「量長度」，用尺量線段、比較兩條線的長短；還有「錢錢應用題」，練習認識錢幣、付錢找錢和加減應用題。收集星星和貼紙。

## 怎麼玩

- **選數字**：點 1～9，決定要練習哪些乘法。也可以全選或清除。
- **看一看（複習）**：用卡片或翻翻卡記住乘法。可以打開「唸口訣」，例如「七七四十九」。
- **來挑戰（考試）**：選 10／20／30 題，可加計時。用畫面上的數字鍵盤或鍵盤作答。
- **應用題（倍的問題）**：用跳著數、連加、「幾倍」的語言和乘法算式（被乘數 × 乘數 = 積）解故事題。可選 5 或 10 題，答對較多還能得到「倍數小專家」徽章。
- **時鐘教學**：圖形教學帶小朋友認識時針（短短紅的）和分針（長長藍的），學會整點、半點、一大格 5 分、一小格 1 分，還能自己撥時鐘。測驗可選整點／半點、5 分鐘或 1 分鐘，答對較多能得到「看時鐘小達人」徽章。
- **量長度**：圖形教學帶小朋友認識尺（一大格是 1 公分），學會從 0 開始量、不從 0 開始量（終點減起點，不要只看終點），還能比較兩條線相差幾公分，並自己拉線練習。測驗分三個難度，答對較多能得到「尺量小專家」徽章。
- **錢錢應用題**：認識 1、5、10、50 元銅板和 100 元鈔票，練習剛好付錢和找錢；再用線段圖、直式加減，解剩下幾元、比多比少、連續給錢、買好幾個等故事題。測驗分三個難度，答對較多能得到「小小理財家」徽章。
- **遊戲獎勵**：答對會得到星星幣和連擊。把某個數字的 1～9 都答對過，就會解鎖一張貼紙。

成績和貼紙會存在這個瀏覽器裡（localStorage），不會上傳。

第一次打開需要網路；載入完成後，這個單頁就可以離線使用（唸口訣的語音和字型若還沒快取，離線時會改用系統字型）。
